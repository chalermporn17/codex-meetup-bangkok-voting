## Platform

web

## Users

DevDay Exchange Community: Bangkok participants browse accepted projects, inspect original prompts, submit projects, and cast one active audience vote per email. Organizers moderate submissions, control event phases, and publish results.

## Product Purpose

Support the One-Shot Build Challenge: 45 minutes, one prompt, and one audience vote per email. Accepted projects appear in the gallery.

## Capabilities and Constraints

Existing plain HTML/CSS/JavaScript frontend with Node and SQLite backend. Preserve event identity, existing routes, API contracts, email-whitelist rules, and confirmation before replacing a vote. Detailed scores are not public before results are published.

The user selected the original Pocket Town (`design-exploration/app.html?direction=town`) on 2026-10-03 after the six-version comparison. This is the approved visual direction for subsequent work. The user authorized applying Pocket Town to the real public site on 2026-10-03. The public landing page, gallery, submission form, results, help, and dialogs now use the selected design and existing Node/SQLite APIs. Organizer pages retain their existing theme. The original design exploration remains a separate demo. No deployment has been performed; verification uses an isolated temporary local database.

## Brand Commitments

Retain the DevDay Exchange Community: Bangkok identity and the selected original Pocket Town composition: split invitation and illustrated town, sage palette, pixel display headings, readable body typography, project-card gallery, and dialogue-style voting. Other directions and variations remain comparison references. Original artwork draws on the supplied era references without copying their characters.

## Accessibility & Inclusion

Readable body and form text, keyboard access, native dialog focus management, reduced motion, usable touch targets, and responsive light/dark rendering are required in the approved plan.

Round-two browser evidence and independent finish review are recorded in design-exploration/validation.md.
