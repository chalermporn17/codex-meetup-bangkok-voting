# Event guide

Public site: <https://codex-meetup-bangkok-voting.gs5zbddkpy.workers.dev>

Organizer: <https://codex-meetup-bangkok-voting.gs5zbddkpy.workers.dev/admin>

## During the event

1. Leave **Submissions** open while people are building.
2. Review each entry and choose **Accept** or **Reject**. Accepted entries appear in the gallery.
3. Choose **Open voting** when the showcase begins. This closes submissions automatically.
4. Attendees vote with their name or Codex handle. Each name and browser can vote once.
5. Choose **Close voting**, then **Publish results**.

Project screenshots are uploaded by participants. Gallery cards open the submitted public project link.
